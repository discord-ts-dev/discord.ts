# Clean-room clone of OwO Bot

We clone the OwO Bot game loop as Paw on discord.ts. The original is CC-BY-NC-SA-4.0: copying its code, data, or assets into this MIT repo would force non-commercial share-alike terms onto the derived work. So we reimplement mechanics only — own code, own roster, own names (Paw, pawcoins) — and copy nothing from the source repo. Rejected: copying `animal.json`/images/names under NC-SA inside `apps/owo`, and forking the original instead of using the framework. Consequence: content parity is manual and slower; the roster starts small.
