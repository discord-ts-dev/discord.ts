NestJS-style Discord bots without NestJS. OOP, DI, lifecycle, and decorators on top of `discord.js` v14.

```ts
import { Injectable, Command, Context } from '@discord.ts/common';
import type { ChatInputCommandInteraction } from 'discord.js';

@Injectable()
export class PingCommand {
  @Command({ name: 'ping', description: 'Reply with pong' })
  async handle(@Context() interaction: ChatInputCommandInteraction) {
    await interaction.reply('pong');
  }
}
```

## Packages

| Package               | Import                          | Use                               |
| --------------------- | ------------------------------- | --------------------------------- |
| `@discord.ts/common`  | decorators, types, logger       | Declare commands, options, events |
| `@discord.ts/core`    | module, routing, guards, config | Boot, sync, dispatch              |
| `@discord.ts/utils`   | pure helpers                    | Mentions, ids, durations          |
| `@discord.ts/systems` | store, daily, quests, shop      | Game systems                      |
| `@discord.ts/ux`      | confirm, pager                  | Interaction helpers               |
| `@discord.ts/cli`     | `discord` runner                | dev, deploy, start                |
