NestJS-style Discord bots without NestJS. OOP, DI, lifecycle, and decorators on top of `discord.js` v14.

```ts
import { Injectable, Command, Context } from '@discord-ts-dev/common';
import type { ChatInputCommandInteraction } from 'discord.js';

@Injectable()
export class PingCommand {
  @Command({ name: 'ping', description: 'Reply with pong' })
  async handle(@Context() interaction: ChatInputCommandInteraction) {
    await interaction.reply('pong');
  }
}
```

## Packages

| Package                   | Import                          | Use                                  |
| ------------------------- | ------------------------------- | ------------------------------------ |
| `@discord-ts-dev/common`  | decorators, types, logger       | Declare commands, options, events    |
| `@discord-ts-dev/core`    | module, routing, guards, config | Boot, sync, dispatch                 |
| `@discord-ts-dev/utils`   | pure helpers                    | Mentions, ids, durations             |
| `@discord-ts-dev/systems` | store, daily, quests, shop      | Game systems                         |
| `@discord-ts-dev/redis`   | `RedisStore`, `redisProviders`  | Store adapter for multi-process bots |
| `@discord-ts-dev/ux`      | confirm, pager                  | Interaction helpers                  |
| `@discord-ts-dev/cli`     | `discord` runner                | dev, deploy, start                   |
