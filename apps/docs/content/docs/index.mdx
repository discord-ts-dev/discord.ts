NestJS-style Discord bots without NestJS. OOP, DI, lifecycle, and decorators on top of `discord.js` v14.

```ts
import { Injectable, Command, Context, CommandContext } from '@discord.ts/common';

@Injectable()
export class PingCommand {
  @Command({ name: 'ping', description: 'Reply with pong', slash: true, prefix: true })
  async handle(@Context() ctx: CommandContext) {
    await ctx.reply('pong');
  }
}
```

## Packages

| Package               | Import                          | Use                               |
| --------------------- | ------------------------------- | --------------------------------- |
| `@discord.ts/common`  | decorators, types, logger       | Declare commands, options, events |
| `@discord.ts/core`    | module, routing, guards, config | Boot, sync, dispatch              |
| `@discord.ts/utils`   | pure helpers                    | Mentions, ids, message checks     |
| `@discord.ts/systems` | store, daily, quests, shop      | Game systems                      |
| `@discord.ts/ux`      | confirm, pager                  | Message helpers                   |
| `@discord.ts/cli`     | `discord` runner                | dev, deploy, start                |
