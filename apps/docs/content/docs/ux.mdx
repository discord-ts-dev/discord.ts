`@discord.ts/ux`. Works on any repliable interaction: command, button, or select.

## Confirm

Yes / No dialog. Text or embed payload. Resolves `true` on accept, `false` on cancel or timeout.

```ts
import { confirm } from '@discord.ts/ux';

const ok = await confirm(interaction, 'Ban this member?', 15_000);
if (ok) await interaction.followUp('banned');

// Lock the buttons to the initiator; others get an ephemeral nudge.
await confirm(interaction, 'Divorce?', { allowedUserId: interaction.user.id });
```

| Arg         | Default | Notes                                                    |
| ----------- | ------- | -------------------------------------------------------- |
| `target`    | —       | Repliable interaction.                                   |
| `question`  | —       | `string` or `{ content?, embeds? }`.                     |
| `timeoutMs` | `15000` | Collector lifetime, or `{ timeoutMs?, allowedUserId? }`. |

Non-authors are nudged with `Not yours to confirm.` and ignored; the collector keeps waiting. Buttons use unique ids per call. After pick it edits to `Confirmed.` / `Cancelled.` and clears components.

## Paginate

Prev / Next embed pager. One page replies direct. Resolves when it times out.

```ts
import { paginate } from '@discord.ts/ux';

await paginate(interaction, [page1, page2, page3], 60_000);

// Lock paging to the viewer.
await paginate(interaction, pages, { allowedUserId: interaction.user.id });
```

| Arg         | Default | Notes                                                    |
| ----------- | ------- | -------------------------------------------------------- |
| `target`    | —       | Repliable interaction.                                   |
| `pages`     | —       | `EmbedBuilder[]`. Empty returns void.                    |
| `timeoutMs` | `60000` | Collector lifetime, or `{ timeoutMs?, allowedUserId? }`. |

Non-authors are nudged with `Not yours to page.` and ignored.

## Author lock

Guard factory for component handlers. Restricts a flow to one initiating user; non-authors get an ephemeral nudge and the handler is skipped.

```ts
import { authorLock } from '@discord.ts/ux';

// Usable via `@UseGuards(authorLock(...))` once core accepts configured
// guard instances (#46). Until then, call it directly:
const locked = authorLock(() => gameId.split('_').pop(), {
  deny: () => 'Not yours to use.',
});
if (!(await locked.canActivate(interaction))) return;
```

Unknown initiator (`resolveUserId` returns `null`/`undefined`) passes through fail-open, deferring to the handler — documented as deliberate. Default deny is `Not yours to use.` (English house style), overridable via `opts.deny(ix)`.

When not to lock: leave open flows open — `drop` claims, `captcha`/`giveaway` presses — and keep multi-party checks (`battle` sides, `trade` receiver/either) app-side.

## Error embed

One red style everywhere. Success embeds stay per-feature.

```ts
import { errorEmbed } from '@discord.ts/ux';

await interaction.reply({ embeds: [errorEmbed('Missing target.')] });
```

## Replies

One delivery path for a Context. It replies when nothing was acknowledged yet,
edits when the Context is already acknowledged, and follows up when an ephemeral
reply is wanted after acknowledgement. It never throws, so a failed delivery
cannot shadow the block it explains.

```ts
import { deliver, replyEmbed, replyEphemeral } from '@discord.ts/ux';

// Guards and refusals: ephemeral, and never lost after a defer or confirm.
await replyEphemeral(interaction, 'Use this command in a server.');

// Results: replace the confirm message, or follow up with a private embed.
await deliver(interaction, { content: 'Restarted.' });
await replyEmbed(interaction, errorEmbed('Ban failed.'), true);
```

| Export           | Notes                                                                                     |
| ---------------- | ----------------------------------------------------------------------------------------- |
| `deliver`        | Full payload (`content`, `embeds`, `components`, extras). Returns the message, or `null`. |
| `replyEphemeral` | Text-only ephemeral.                                                                      |
| `replyEmbed`     | One embed, private when the third argument is `true`.                                     |
| `ReplyTarget`    | Structural target shape; real interactions satisfy it.                                    |

It picks the method from the target's state and never defers for you. A handler that does slow work calls `deferReply()` on the interaction first, then delivers into the deferred target.
