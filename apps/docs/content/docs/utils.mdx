`@discord.ts/utils`. Zero framework deps. Pure string checks.

```ts
import { parseMentionId, isSnowflake, userIdOf } from '@discord.ts/utils';

parseMentionId('<@123>'); // '123'
parseMentionId('<@&456>'); // role id
parseMentionId('<#789>'); // channel id
```

| Function              | Input                                | Output                         |
| --------------------- | ------------------------------------ | ------------------------------ |
| `parseMentionId(raw)` | mention or raw digits                | id or `undefined`              |
| `userIdOf(raw)`       | `User` object or mention / id string | id or `undefined`              |
| `isSnowflake(id)`     | string                               | `true` for strict 17–20 digits |

Use `isSnowflake()` when a real Discord id shape is required. `parseMentionId()` is lenient on length.

## Amounts

Parse `100`, `1,000`, `2k`, `1.5m`, `all` / `max` (= balance). Floored to ints.

```ts
import { parseAmount } from '@discord.ts/utils';

parseAmount('2k', 5000); // { ok: true, value: 2000 }
```

Fail reasons: `invalid` | `non-positive` | `exceeds-balance`.

## Words

Word-boundary, case-insensitive blocklist.

```ts
import { containsBlocked, maskBlocked } from '@discord.ts/utils';

containsBlocked('hello spam', ['spam']); // true
maskBlocked('hello spam', ['spam']); // 'hello ***'
```

These match whole words. For substring filtering (an OwO-style censor), see the [word filter recipe](/docs/recipes/word-filter).

## Vote payload

top.gg webhook bodies carry the voter id in `user`. Parsing is here; awarding is Store-backed, so it lives in `systems`.

```ts
import { parseVotePayload } from '@discord.ts/utils';

const voter = parseVotePayload(body); // string | null
```

For a webhook handler with auth and dedupe, see the [vote webhook recipe](/docs/recipes/vote-webhook).
