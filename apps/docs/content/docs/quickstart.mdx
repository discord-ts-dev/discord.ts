---
title: Quickstart
description: Boot a bot in five minutes. Install, declare, sync, run.
---

## 1. Install

Requires Bun `>=1.4.2`.

```bash
bun add @discord-ts-dev/core @discord-ts-dev/common @discord-ts-dev/cli discord.js reflect-metadata
```

`@discord-ts-dev/core` pulls in `@discord-ts-dev/i18n`, `@discord-ts-dev/utils` and
`@discord-ts-dev/ux`. Add `@discord-ts-dev/systems` for store-backed features and
`@discord-ts-dev/redis` for the Redis store.

`@discord-ts-dev/cli` provides the `discord` binary. Point your scripts at it:

```json
{
  "scripts": {
    "dev": "discord dev",
    "deploy": "discord deploy",
    "start": "discord start"
  }
}
```

## 2. Configure

Create `discord.config.ts` at the app root. Secrets come from env.

```ts
import { GatewayIntentBits } from 'discord.js';
import { defineConfig } from '@discord-ts-dev/core';

export default defineConfig({
  token: 'test-token',
  clientId: 'test-client',
  intents: [GatewayIntentBits.Guilds, GatewayIntentBits.GuildMessages],
});
```

Env wins over file: `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`, `DISCORD_GUILD_ID`, `SKIP_REGISTRATION`, `SHARD_COUNT`.

## 3. Declare

```ts
import { Injectable, Command, Context } from '@discord-ts-dev/common';
import type { ChatInputCommandInteraction } from 'discord.js';

@Injectable()
export class PingCommand {
  @Command({ name: 'ping', description: 'Reply with pong' })
  async handle(@Context() interaction: ChatInputCommandInteraction) {
    await interaction.reply('pong');
  }
}
```

Register the provider in your module:

```ts
import { Module } from '@discord-ts-dev/common';
import { DiscordModule } from '@discord-ts-dev/core';

@Module({
  imports: [DiscordModule.forRootAsync()],
  providers: [PingCommand],
})
export class AppModule {}
```

## 4. Sync

Sync without login. Use it in CI. `discord deploy` runs `src/deploy.ts`, so the
snippet above belongs in that file.

```bash
bun run deploy
```

```ts
// src/deploy.ts
import 'reflect-metadata';
import { deployWithModule } from '@discord-ts-dev/core';
import { AppModule } from './app.module';

const { count } = await deployWithModule(AppModule);
console.log(`Deployed ${count} commands.`);
```

## 5. Run

`discord dev` runs `src/main.ts`, so the snippet below belongs in that file.

```ts
import 'reflect-metadata';
import { bootstrapApp } from '@discord-ts-dev/core';
import { AppModule } from './app.module';

void bootstrapApp(AppModule);
```

```bash
bun run dev      # src/main.ts via bun
bun run deploy   # src/deploy.ts, sync only
bun run start    # dist/main.js, after build
```

Each script is a `@discord-ts-dev/cli` command from step 1. `dev` runs TypeScript
source directly, so it needs no build step; `start` runs build output, so build
first.
