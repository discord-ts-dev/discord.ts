## Command

Declare a `/name` handler. Method-level only. The class stays plain `@Injectable()`.

```ts
import { Injectable, Command, Context } from '@discord.ts/common';
import type { ChatInputCommandInteraction } from 'discord.js';

@Injectable()
export class RollCommand {
  @Command({ name: 'roll', description: 'Roll dice' })
  async handle(@Context() interaction: ChatInputCommandInteraction) {
    await interaction.reply('rolled');
  }
}
```

| Field                      | Type                                 | Notes                                            |
| -------------------------- | ------------------------------------ | ------------------------------------------------ |
| `name`                     | `string`                             | Lowercase, Discord rules apply. Checked at boot. |
| `description`              | `string`                             | Required by Discord.                             |
| `nsfw`                     | `boolean`                            | Age-restricted channel only.                     |
| `defaultMemberPermissions` | `string \| number \| bigint \| null` | Caller permission floor.                         |
| `contexts`                 | `InteractionContextType[]`           | Where the command shows.                         |
| `dmPermission`             | `boolean`                            | Allow use in DMs.                                |
| `nameLocalizations`        | `LocalizationMap`                    | Localized names.                                 |
| `descriptionLocalizations` | `LocalizationMap`                    | Localized descriptions.                          |
| `category`                 | `string`                             | Help grouping label. Raw string, top level only. |
| `toggleable`               | `boolean`                            | Guilds may switch it off. Default `false`.       |

## Help metadata

`category` and `toggleable` ride on `@Command()` and group metadata and surface through
`DiscordDiscoveryService.helpEntries()`: one `HelpEntry` per top-level command (a group counts
once, by group name), with descriptions already merged against the i18n catalog. `toggleable` is
informational — it feeds enable/disable choice sources, never enforcement, which stays with the
`guild:` settings and `EnabledGuard`. A value on a subcommand or sub-group changes nothing and
logs one boot warning. Help rendering from the registry lives in
[systems helpers](/docs/systems/helpers).

## Localization

Metadata localizations come from two sources, merged per locale. Explicit maps win.

Catalog keys live in the `commands` namespace of `@discord.ts/i18n`:

| Key                                                                        | Use                         |
| -------------------------------------------------------------------------- | --------------------------- |
| `commands:<name>.name` / `.description`                                    | Top-level command or group. |
| `commands:<name>.subcommands.<sub>.name` / `.description`                  | Subcommand.                 |
| `commands:<name>.groups.<group>.name` / `.description`                     | Subcommand group.           |
| `commands:<name>.options.<option>.name` / `.description`                   | Option.                     |
| `commands:<name>.subcommands.<sub>.options.<option>.name` / `.description` | Option of a subcommand.     |

Only Discord locale codes are read (`en-US`, `id`, `ja`, ...). Locale dirs Discord does not
recognize are skipped with one boot warning. Option and choice names can also carry explicit
`nameLocalizations` / `descriptionLocalizations` maps on the decorator.

## Subcommand and group

Children of a command or group. Make a group with the factory, then add `@Subcommand()` methods.

```ts
import { createCommandGroupDecorator, Subcommand, Context } from '@discord.ts/common';
import type { ChatInputCommandInteraction } from 'discord.js';

const Quest = createCommandGroupDecorator({ name: 'quest', description: 'Daily quests' });

@Injectable()
@Quest()
export class QuestCommand {
  @Subcommand({ name: 'rr', description: 'Reroll your quest' })
  async reroll(@Context() interaction: ChatInputCommandInteraction) {
    await interaction.reply('Rerolled.');
  }
}
```

A method-level `@Quest({ subgroup })` nests via the parent chain. Discovery validates names, limits, and duplicates and throws one aggregated error before any REST call.

## ContextMenu

Right-click action on a user or message.

```ts
@ContextMenu({ name: 'Report', type: ApplicationCommandType.Message })
async handle(@Context() interaction: MessageContextMenuCommandInteraction) {
  await interaction.reply('reported');
}
```

| Field  | Notes                                        |
| ------ | -------------------------------------------- |
| `name` | Display name.                                |
| `type` | `ApplicationCommandType.User` or `.Message`. |

## Migrating from prefix commands

The prefix surface is removed. Map the old pieces:

| Before                                    | After                                                   |
| ----------------------------------------- | ------------------------------------------------------- |
| `@PrefixCommand({ name: 'echo' })`        | `@Command({ name: 'echo', description: '...' })`        |
| `@PrefixArgs() args: string[]`            | `@Options() dto: Dto` with option decorators            |
| `@Command({ slash: true, prefix: true })` | `@Command({ ... })` — every command is a slash command. |
| `@SlashCommand({ ... })`                  | `@Command({ ... })`                                     |
| `prefix` in `discord.config.ts`           | Delete it.                                              |
| `CommandContext`                          | `ChatInputCommandInteraction` via `@Context()`.         |
| Prefix aliases and sub-routes             | Slash choices and autocomplete.                         |
| `setPrefix()` guild setting               | Gone; commands are `/name` everywhere.                  |
