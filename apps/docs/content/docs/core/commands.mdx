title: Commands
description: Slash, subcommand, group, and context menu. One handler per surface.

## SlashCommand

Declare a `/name` handler. Method-level only. The class stays plain `@Injectable()`.

```ts
import { Injectable, SlashCommand, Context } from '@discord.ts/common';

@Injectable()
export class RollCommand {
  @SlashCommand({ name: 'roll', description: 'Roll dice' })
  async handle(@Context() interaction: ChatInputCommandInteraction) {
    await interaction.reply('rolled');
  }
}
```

| Field | Type | Notes |
| ----- | ---- | ----- |
| `name` | `string` | Lowercase, Discord rules apply. Checked at boot. |
| `description` | `string` | Required by Discord. |
| `nsfw` | `boolean` | Age-restricted channel only. |
| `defaultMemberPermissions` | `string \| number \| bigint \| null` | Caller permission floor. |
| `contexts` | `InteractionContextType[]` | Where the command shows. |

## Command (unified)

One handler on slash and prefix. At least one of `slash` / `prefix` must be `true`.

```ts
@Command({ name: 'ping', description: 'Reply with pong', slash: true, prefix: true })
async handle(@Context() ctx: ChatInputCommandInteraction | Message) {
  await ctx.reply('pong');
}
```

| Field | Notes |
| ----- | ----- |
| `slash` | Register as slash command. |
| `prefix` | Register as prefix command under the same name. |
| `aliases` | Extra text triggers for the prefix surface. |

## Subcommand and group

Children of a command or group. Make a group with the factory, then add `@Subcommand()` methods.

```ts
import { createCommandGroupDecorator, Subcommand } from '@discord.ts/common';

const Quest = createCommandGroupDecorator({ name: 'quest', description: 'Daily quests' });

@Injectable()
@Quest({ prefix: true })
export class QuestCommand {
  @Subcommand({ name: 'rr', description: 'Reroll your quest' })
  async reroll(@Context() ctx: Ctx) {
    await ctx.reply('Rerolled.');
  }
}
```

Group flags pick surfaces: `slash` defaults `true`, `prefix` defaults `false`. A method-level `@Quest({ subgroup })` nests via the parent chain. A `@Subcommand()` on a `@Command()` parent nests on every surface the parent enables. Discovery validates names, limits, and duplicates and throws one aggregated error before any REST call.

## ContextMenu

Right-click action on a user or message.

```ts
@ContextMenu({ name: 'Report', type: ApplicationCommandType.Message })
async handle(@Context() interaction: MessageContextMenuCommandInteraction) {
  await interaction.reply('reported');
}
```

| Field | Notes |
| ----- | ----- |
| `name` | Display name. |
| `type` | `ApplicationCommandType.User` or `.Message`. |
