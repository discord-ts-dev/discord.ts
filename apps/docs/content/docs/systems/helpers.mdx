## Votes

top.gg webhook bodies carry the voter id in `user`. Parsing is pure (`utils`); awarding is Store-backed.

```ts
import { parseVotePayload } from '@discord.ts/utils';
import { awardVote } from '@discord.ts/systems';

const voter = parseVotePayload(body); // string | null
if (voter) await awardVote(store, voter, 100); // stamps vote: + adds balance
```

No signature check here. Verify webhook secrets at the HTTP layer before calling `awardVote()`.

## Help

Group and sort `{ name, description, category? }` into sections. `General` sorts last.

```ts
import { buildHelp } from '@discord.ts/systems';

buildHelp([{ name: 'ping', description: 'Pong' }]);
// [{ category: 'General', commands: [...] }]
```

## Guild settings

Per-guild prefix and per-command toggles in `guild:` keys.

```ts
import { getSettings, setPrefix, setCommandEnabled, isCommandEnabled } from '@discord.ts/systems';

await setPrefix(store, guildId, '?');
await setCommandEnabled(store, guildId, 'shop', false);
await isCommandEnabled(store, guildId, 'shop'); // false
```
